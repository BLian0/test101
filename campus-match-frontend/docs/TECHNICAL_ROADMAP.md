# 校园搭子技术路线

## 1. 总体路线

第一版技术路线：

- 前端：`uni-app + Vue 3 + TypeScript + Pinia`
- 后端：`NestJS + MySQL + Redis`
- 文件：`对象存储`
- 管理后台：`Vue 3 + Element Plus`
- 部署：`Docker + Nginx`

目标是先完成 `H5 内测版`，后续平滑迁移到微信小程序。

## 2. 为什么这样选

### 前端选择 uni-app

原因：

- 你后续目标明确包含微信小程序
- 现在又要先做 H5 内测
- 一套代码覆盖 H5 和小程序更合适

约束：

- 从第一天就按 uni-app 规范写
- 不按传统纯 Web DOM 项目写

### 后端选择 NestJS

原因：

- 业务模块边界清晰
- 适合做模块化单体
- 适合后续增加后台、风控、问卷和推荐逻辑

### 数据库选择 MySQL

原因：

- 结构化业务非常多
- 关系清晰
- 事务和约束重要

### Redis 的作用

用于：

- 验证码缓存
- 登录态辅助
- 热门推荐缓存
- 限流

## 5. 问卷与匹配路线

### 第一版算法策略

第一版不做复杂 AI 算法，建议采用：

- 基础资料硬筛选
- 标签匹配
- 维度分差值计算
- 偏好权重加分

### 第一版计算步骤

1. 用户提交问卷
2. 生成标签
3. 生成 trait 分数
4. 与目标用户做规则匹配
5. 输出匹配分
6. 输出匹配解释

### 后续升级空间

- 问卷权重调优
- 人群分层
- 行为数据反哺推荐
- 机器学习排序
